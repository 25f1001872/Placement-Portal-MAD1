# Placement Portal Application (MAD-I)

## 📌 Project Overview

The Placement Portal Application is a role-based web application designed to manage campus recruitment activities efficiently.  
The system allows the Institute (Admin), Companies, and Students to interact through a structured placement workflow including company approvals, placement drive management, and application tracking.

This project is developed as part of the **Modern Application Development – I (MAD-I)** course.

---

## 🛠 Tech Stack

- **Backend:** Flask  
- **Frontend:** Jinja2, HTML, CSS, Bootstrap  
- **Database:** SQLite (Programmatically Created)  
- **Language:** Python  

---

## 👥 System Roles

### 🔹 Admin (Institute Placement Cell)
- Approve or reject company registrations  
- Approve or reject placement drives  
- Manage students, companies, and drives  
- Search and blacklist users  
- View overall placement statistics  

### 🔹 Company
- Register and create company profile  
- Create and manage placement drives (after admin approval)  
- View student applications  
- Update application status  

### 🔹 Student
- Register and manage profile  
- View approved placement drives  
- Apply for drives  
- Track application status and placement history  

---

## 🚀 Core Features

- Role-based authentication system  
- Company and placement drive approval workflow  
- Prevention of duplicate applications  
- Application status tracking (Applied / Shortlisted / Selected / Rejected)  
- Complete placement history maintenance  
- Programmatic database creation (No manual DB setup)  

---

## 📂 Project Structure

The application follows a modular Flask structure with separate routes, models, and templates to maintain clean architecture and role separation.
